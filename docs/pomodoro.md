## config.toml への追加

```toml
[pomodoro]
focus_minutes    = 25
break_minutes    = 5
sets             = 4
auto_start_break = true   # 集中終了後、自動で休憩へ移行するか
auto_start_focus = true   # 休憩終了後、自動で次の集中へ移行するか
```

## tools/generate_voice/

### input_voices.json フォーマットへの追加

`pomodoro` を新たなトップレベルキーとして追加する。
複数バリエーションを持てるよう `texts`（複数形）を使う。

```json
{
    "time_signal": [...],
    "clicked": [...],
    "pomodoro": [
        {
            "name": "pomodoro_focus_start",
            "texts": ["よし、集中していこう！", "頑張れ！応援してるよ。"]
        },
        {
            "name": "pomodoro_break_start",
            "texts": ["お疲れ様。ちゃんと手を止めてね。", "休憩も仕事のうちだよ。"]
        },
        {
            "name": "pomodoro_finish",
            "texts": ["全部終わったよ。お疲れ様でした！", "よく頑張ったね。"]
        },
        {
            "name": "pomodoro_interrupt",
            "texts": ["ここまでだね。", "中断するよ。またね。"]
        }
    ]
}
```

### ファイル命名規則

`clicked` と同じルールに従う。

```
pomodoro_focus_start_001.wav
pomodoro_break_start_001.wav
pomodoro_finish_001.wav
pomodoro_interrupt_001.wav
```

### gen_voice.py への対応

`pomodoro` セクションの処理は `clicked` と同一ロジックで吸収する。
`"name"` キーの存在バリデーションも同様に行う。

## main.py 画面構成

### 全体レイアウト

右列にポモドーロエリアを追加する。

```
┌──────────────────────────────────┐
│ [キャラクター画像]  │  HH:MM     │
│                    │            │
│                    │ ポモドーロ  │
│                    │  タイマー  │
│                    │ [操作ボタン]│
└──────────────────────────────────┘
```

### ポモドーロ表示エリア（右列 / 時計の下）

| 要素 | 内容 |
|---|---|
| フェーズ表示 | `集中 2 / 4` など現在セット数を表示 |
| タイマー | `MM:SS` 形式、中央寄せ大文字で表示 |
| 操作ボタン | 下記参照 |

### 操作ボタン（左から順に）

| 位置 | ラベル（状態による切り替え） | 動作 |
|---|---|---|
| 左 | **開始** / **中止** | 未開始→セッション開始、実行中→セッション全体を中止 |
| 中 | **一時停止** / **再開** | トグル。未開始時は非活性 |
| 右 | **スキップ** | 現在フェーズを終了して次へ。未開始時は非活性 |

## ポモドーロ動作仕様

### フェーズ遷移

```
[集中] → [休憩] → [集中] → ... → [全セット完了]
```

- `auto_start_break = true` のとき、集中終了後に自動で休憩へ移行する
- `auto_start_focus = true` のとき、休憩終了後に自動で次の集中へ移行する
- `false` のとき、タイマーは 0 で止まりユーザーの「再開」操作を待つ

### 音声再生ルール

| タイミング | 再生カテゴリ | 備考 |
|---|---|---|
| 集中フェーズ開始 | `pomodoro_focus_start` | 複数ある場合はランダム |
| 休憩フェーズ開始 | `pomodoro_break_start` | 同上 |
| 全セット完了 | `pomodoro_finish` | 同上 |
| セッション中止 | `pomodoro_interrupt` | 同上 |
| 時報（`time_signal`） | **実行中のみ停止** | 一時停止中は通常通り再生する |
| クリック（`clicked`） | **常に再生** | ポモドーロ実行状態に関わらず有効 |

- 「実行中」とは、開始後〜完了 or 中止までのうち、**一時停止中を除く** 期間を指す
- スキップ操作時は、遷移先フェーズの音声を通常通り再生する

### 状態定義

| 状態 | 時報 | クリック音 |
|---|---|---|
| 未開始 | ○ | ○ |
| 実行中（集中 / 休憩） | **×** | ○ |
| 一時停止中 | ○ | ○ |
| 完了 / 中止後 | ○ | ○ |
